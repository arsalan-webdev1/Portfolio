Three flat files form a classic static-site layout with no build step: `index.html` is the single-page shell (sections for Home/About/Skills/Journey/Projects/Contact), `style.css` holds all design tokens (`:root` variables for colors, radii, easing) and component styles (glass cards, timeline, responsive breakpoints at 960/820/560px), and `script.js` boots on `DOMContentLoaded`. The script is organized into feature blocks — welcome overlay gate, project rendering from a `projects` array, rAF-throttled scroll handler (progress bar + nav state + timeline fill), mobile burger menu, IntersectionObserver-based reveal/timeline activation, active-section tracking via `body[data-mood]`, and desktop-only pointer effects (ambient glow, magnetic buttons, 3D tilt). CSS custom properties drive most motion (`--d` stagger delays, `--fill` timeline draw, `--px/--py` mouse offset, `--rx/--ry` tilt, `--mx/--my` magnet pull), keeping animation logic declarative. There are no sub-packages or frameworks; dependencies flow one-way from HTML → CSS + JS.
